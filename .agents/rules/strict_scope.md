# Strict Scoping & Minimal Intervention Rules

이 프로젝트에서 작업할 때 AI 에이전트는 다음 행동 원칙을 절대적으로 준수해야 합니다.

1. **외과수술식 최소 개입 (Surgical & Minimal Intervention)**:
   - 사용자가 요청한 특정 버그, 특정 파일, 특정 데이터 범위만 정확히 수정한다.
   - 지시받지 않은 주변 코드 리팩토링, 불필요한 추상화 레이어 추가를 엄격히 금지한다.

2. **추측성 코딩 금지 (No Speculative Over-Engineering)**:
   - "미래를 위해 미리" 등의 이유로 사용자가 요구하지 않은 미래 데이터나 기능을 임의로 구현하지 않는다.

3. **'제안'과 '실행'의 엄격한 분리 (Propose First, Code Later)**:
   - 더 좋은 구조나 아이디어가 떠오르더라도 절대 코드를 먼저 작성하지 않는다.
   - 요청받은 작업만 마친 뒤, 텍스트로 1~2줄 제안만 남기고 사용자의 명시적 승인을 기다린다.

4. **커뮤니케이션 제약 존중 (Brevity & Directness)**:
   - `확인만`, `구상만`, `코멘트 달지 마` 등의 지시어는 설명 없이 본론만 간결히 수행한다.
